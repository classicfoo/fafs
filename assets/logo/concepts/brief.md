# Search logo brief

**Summary:** A desktop app that helps people find a particular file or folder by name across nested directories.

**Audience:** People who manage many local files and want a quick, dependable desktop tool.

**Brand adjectives:** precise, swift, quiet, dependable. **Avoid:** cluttered, whimsical, intrusive.

**Promise:** Find the item you need without interrupting your work.

**Category:** File utilities and developer productivity tools often use blue, circular search lenses, folder tabs, and gradients. These concepts avoid the magnifying-glass cliché and start in black and white.

**Mark types explored:** A pictorial index, an abstract path, and a custom S letterform.

**Must work on:** Linux and Windows app icons, taskbar/start menu, and at 16 px in one colour.

**Constraints:** The product name is exactly `Search`. No existing logo equity or color preference was provided. The current interface uses a deep teal selection accent; it is only a provisional context for the tests.

**Success criteria:** The mark remains legible at 16–24 px, works in monochrome, and avoids common search and folder symbols.

**Assumptions:** This is a practical utility for people who prefer a focused, restrained tool. I treated the app icon as the primary use and did not build a full wordmark system before concept selection.
